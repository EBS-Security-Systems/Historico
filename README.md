# Historico
Projetos pioneiros da EBS Security Systems de 08/2021

## Encription Creator

Esse projeto foi desenvolvido por [Thiago Sousa](https://github.com/thiagosousa81) em meados de Novembro de 2021
<br>
Destinou-se a testar o uso da encriptação múltipla e do RSA, que nunca foi implementado aqui

Uma derivação dele foi levada à FECIBA em 2022 e publicada finalmente como [**Encryption's Builder Studio**](https://thiagosousa81.wordpress.com/ebs/)
