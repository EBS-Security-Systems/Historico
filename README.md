## Encryption Master v3.0

Esse primeiro projeto foi desenvolvido por [Thiago Sousa](https://github.com/thiagosousa81) em meados de Setembro de 2021
<br>
Destinou-se a compreender o uso do Base64 e do hash MD5. 

O projeto como um todo foi danificado e precisou ser restaurado pois a estrutura do design foi projetada para um monitor muito maior.
